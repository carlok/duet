## (x·x)·y = y by hand, from E's 25-step proof

**Commutativity**, one step. C with y := x∘z reads (x·b)·(x∘z) = x∘z with b = (x∘(x∘z))·x. A says the left side
is z∘x.

With commutativity, A says: (∗) x∘z is fixed by every left translation by an element of x·S, and of z·S.
1. **L1:** (x∘y)·((y·z)∘w) = (y·z)∘w. A gives x∘y = (y·z)·(y∘x), an element of (y·z)·S, so it fixes (y·z)∘w by (∗).
2. Let e = y∘(y·z) = (y·z)∘y. By L1, e·e = e and (e∘y)·e = e. C with x := e gives (e·e)·y = y, so e·y = y.
3. L1 with y := e, and e·y = y, give (x∘e)·(y∘w) = y∘w. With w := y·z this is (x∘e)·e = e. C with x := e, y := x
   then gives (e·e)·x = x. So e is a left identity.
4. C with y := x·y: by 3, (x∘(x·y))·x = x, so (x·x)·(x·y) = x·y. In particular (y·y)·(y·y) = y·y.
5. Let a = z∘(y·y). By L1 and 4, a·a = a and (a∘y)·a = a. C with x := a gives (a·a)·y = y, so a·y = y.
6. C with x := x·y, y := x, and 3: ((x·y)·(x·y))·x = x. Apply this to q = (x·y)·(x·y) and x, using q·x = x:
   (x·x)·q = q.
7. Step 6 with x := a from 5, and a·y = y: (a·a)·(y·y) = y·y, so a·(y·y) = y·y.
8. C with x := y·y, y := z: by 7, ((y·y)·(y·y))·z = z; by 4, (y·y)·z = z.

## The models, in general

**Theorem.** Let (S, ·) be a magma. For x, y in S let

W₂(x,y) = { w : p·w = w for every p in x·S ∪ y·S, (x·(w·x))·y = y and (y·(w·y))·x = x }.

The models of T2 are exactly the pairs (·, ∘) with ∘ commutative and x∘y ∈ W₂(x,y) for all x, y.

*Proof.* T2 proves commutativity. With it, A says that x∘z is fixed by every left translation from x·S and from z·S.
C, read for (x, y) and for (y, x), is the other two conditions on the one value x∘y = y∘x. ∎

## Reading

`1f430506` and `1238c063` are a natural pair: the same first law, the same synergy, the same reducts. The second law
only decides which commutative choices of x∘y are allowed.
- B asks x∘y to turn every square into a left translation that fixes x and y.
- C asks that x·((x∘y)·x) fix y from the left, and the same with x and y swapped.

On 2 and 3 elements the two conditions allow exactly the same ∘, and both follow from V. They part from 4 elements on.
The pattern of the earlier memos holds again: ∘ is a constrained choice, not an operation with laws of its own.
